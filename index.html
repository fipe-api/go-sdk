Go SDK for the FIPE API

github.com/fipe-api/go-sdk is a typed Go client for the average vehicle prices of the Brazilian market (Tabela FIPE). It covers cars, motorcycles and trucks. You do not write HTTP or JSON code.

Go 1.22+ Zero dependencies context.Context on every call MIT license

Install

Add the module to your project:

go get github.com/fipe-api/go-sdk

Import it with the fipe name: fipe "github.com/fipe-api/go-sdk"

Quick start

Create a client with fipe.New and send a query. You do not need configuration or a token to start:

package main

import (
	"context"
	"fmt"
	"log"

	fipe "github.com/fipe-api/go-sdk"
)

func main() {
	client := fipe.New()
	ctx := context.Background()

	brands, err := client.Brands(ctx, fipe.Cars)
	if err != nil {
		log.Fatal(err)
	}
	for _, b := range brands {
		fmt.Println(b.Code, b.Name)
	}
}

Vehicle types are constants of type fipe.VehicleType: fipe.Cars, fipe.Motorcycles and fipe.Trucks.

Get a price

Go from brand to model to year to get the average price of a vehicle:

models, _ := client.Models(ctx, fipe.Cars, "59")
years, _ := client.Years(ctx, fipe.Cars, "59", "5940")
vehicle, _ := client.Vehicle(ctx, fipe.Cars, "59", "5940", "2014-3")

fmt.Println(vehicle.Model, vehicle.Price)

If you know the FIPE code of the vehicle, use it directly:

vehicle, _ := client.VehicleByFipeCode(ctx, fipe.Cars, "005340-6", "2014-3")
history, _ := client.HistoryByFipeCode(ctx, fipe.Cars, "005340-6", "2014-3")

for _, h := range history.PriceHistory {
	fmt.Println(h.Month, h.Price)
}

Configuration

Authentication

The client works without a token on the free tier. The free tier has a rate limit. To use a subscription token:

client := fipe.New(fipe.WithSubscriptionToken("your-token"))

HTTP client and timeouts

Every method takes a context.Context. Use it to set a deadline or to cancel a request. To change the transport, give your own *http.Client:

client := fipe.New(
	fipe.WithHTTPClient(&http.Client{Timeout: 10 * time.Second}),
	fipe.WithSubscriptionToken("your-token"),
)

ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()

brands, err := client.Brands(ctx, fipe.Cars)

fipe.WithBaseURL changes the API base URL. Use it to point the client to a test server.

Reference months

The API publishes prices in monthly reference tables. Every method accepts fipe.WithReference to query a past month:

refs, _ := client.References(ctx) // e.g. {Code: "308", Month: "abril de 2024"}

brands, _ := client.Brands(ctx, fipe.Cars, fipe.WithReference(308))

Client methods

All methods take a context.Context, return typed values and an error, and accept optional fipe.RequestOption values.

Error handling

A non-2xx response returns a *fipe.APIError with the HTTP status code and the response body. A 404 matches fipe.ErrNotFound and a 429 matches fipe.ErrTooManyRequests with errors.Is:

vehicle, err := client.Vehicle(ctx, fipe.Cars, "59", "5940", "1900-1")
switch {
case errors.Is(err, fipe.ErrNotFound):
	// unknown brand, model or year
case errors.Is(err, fipe.ErrTooManyRequests):
	// rate limited: wait, or use a subscription token
case err != nil:
	var apiErr *fipe.APIError
	if errors.As(err, &apiErr) {
		log.Printf("API returned %d: %s", apiErr.StatusCode, apiErr.Body)
	}
}

FAQ

Which Go versions are supported?

The module requires Go 1.22 or later. It uses only the standard library and has no third-party dependencies.

Do I need an API token?

No. The SDK works without a token on the free tier. The free tier has a rate limit. Pass fipe.WithSubscriptionToken to fipe.New to lift the limits. The FIPE API issues the tokens.

Can I share one client between goroutines?

Yes. The fipe.Client does not change after fipe.New, and *http.Client is safe for concurrent use. Create one client and use it in all goroutines.

Where does the data come from?

The prices come from the FIPE API. It publishes the Tabela FIPE: the average vehicle prices of the Brazilian market from Fundação Instituto de Pesquisas Econômicas. The data changes every month.

Is there a runnable example?

Yes. The repository has an example program. Run go run ./examples to list brands and show a live price.
